1. LiberationSans-Regular.ttf
   Liberation Sans, Regular weight.
   Copyright: (c) 2012, Ascender Corporation, Steve Matteson.
   License: SIL Open Font License, Version 1.1.
   Used for: body text, captions and sub-captions ("ViceSans", weight 400).

2. LiberationSans-Bold.ttf
   Liberation Sans, Bold weight.
   Copyright: (c) 2012, Ascender Corporation, Steve Matteson.
   License: SIL Open Font License, Version 1.1.
   Used for: buttons, headings and sub-captions ("ViceSans", weight 700).

3. ViceDisplay-SemiBold.ttf
   Noto Sans Display Condensed, SemiBold weight.
   Copyright: (c) 2022, Google Inc. (Noto project).
   License: SIL Open Font License, Version 1.1.
   Used for: section headings and secondary display text
   ("ViceDisplay", weight 600).

4. ViceDisplay-ExtraBold.ttf
   Noto Sans Display Condensed, ExtraBold weight.
   Copyright: (c) 2022, Google Inc. (Noto project).
   License: SIL Open Font License, Version 1.1.
   Used for: the big poster title and the app wordmark
   ("ViceDisplay", weight 800).

No Rockstar Games font is used. The display faces are renamed here to
"ViceDisplay" only as a local file name; the font data itself is the
unmodified Noto Sans Display Condensed release.

Files were copied unmodified from the system font directories; only the
two Noto Sans Display files were renamed to ViceDisplay-*.ttf.
